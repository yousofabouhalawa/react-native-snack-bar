# react-native-snack-bar

A native iOS and Android snack bar in react native.

## Installation


```sh
npm install react-native-snack-bar
```


## Usage


```js
import { SnackBarView } from "react-native-snack-bar";

// ...

<SnackBarView color="tomato" />
```
